# nmap-localhost-acan
Nmap localhost scan with port analysis on windows
## Command Used
**nmap -sV localhost**
Key Results
135/tcp open  msrpc – Microsoft Windows RPC

445/tcp open  microsoft-ds – SMB file sharing

902/tcp open  ssl/vmware-auth – VMware Authentication Daemon

912/tcp open  vmware-auth – VMware Authentication Daemon

See output/nmap-localhost.txt for full scan output and notes/port-analysis.md for detailed explanations.
